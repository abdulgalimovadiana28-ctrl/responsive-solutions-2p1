# Responsive Solutions — 2Р1

Адаптивная вёрстка по макету Nicepage «Responsive Solutions».

## Технологии
- HTML5
- CSS3
- CSS Grid и Flexbox
- Media Queries

JavaScript не используется.

## Запуск
Откройте файл `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте GitHub-репозиторий.
2. Загрузите `index.html`, `style.css` и `README.md` в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите Save.
